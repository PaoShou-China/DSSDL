# Original-paper baseline implementations

This directory retains the main implementations of four baselines without their duplicated datasets, old models or historical plots. They are reading references for code walkthroughs, not directly runnable packaged entry points. Their original relative imports are retained. Connecting them directly to the main method's data is not, by itself, a complete reproduction of the paper. Use `../run.py` for the current runnable experiments.
