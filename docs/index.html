THE METHOD / 01

相同规律，不同系统。

共享网络刻画跨任务共性，低维特性向量表示任务差异。符号模型为学到的动力学提供可解释结构。

DYNAMICS MODEL

ẋ = fθ(x, q) + fs(x, q)

神经分量符号分量q · 任务特性
  1. 01

    多任务学习

    从源任务观测中训练共享网络与任务表示，分离共性和个性。

    source observations → θ, q
  2. 02

    符号搜索

    PySR 拟合网络响应，以源任务验证误差与复杂度筛选候选表达式。

    frozen network → expressions
  3. 03

    结构整理与回填

    整理系数函数，记录近似删项。LLM 辅助、作者确认后固定结构再训练。

    expressions → fs → feedback
  4. 04

    新任务适配

    冻结离线共享模型，以支持集更新特性向量，再评估未见观测。

    support observations → qnew
