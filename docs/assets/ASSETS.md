# Visual assets

- `hero.png`: generated scientific identity illustration, not experimental data.
- `mark.png`: generated original DSSDL emblem with transparency; not the Beihang seal.
- `overview.png`: generated generic workflow overview, not an equation-recovery result.
- `results.js`: deterministic export of the repository's original FHN/Lorenz CSVs.
- `lucide.min.js`: Lucide 0.468.0; its license is included as `LUCIDE-LICENSE`.

The blue/white/red visual direction is inspired by Beihang's
[visual identity resources](https://xcb.buaa.edu.cn/vixt.htm). The page is a research
project page, not an official university website.

The three original bitmap assets were made with the built-in image-generation
tool. The retained prompt specifications are:

1. Hero: white scientific studio, blue/silver Lorenz-attractor sculpture with an
   aerodynamic wing section, red/teal trajectory accents, negative space at left,
   no text, seal, numeric results, or decorative glowing orbs.
2. Mark: original compact swept-wing/trajectory emblem suggesting D, science blue
   and a red accent, genuinely transparent background, no text or university crest.
3. Overview: four stages (Learn, Discover, Consolidate, Adapt); shared network and
   task coordinates; PySR with validation/complexity selection; coefficient
   collection with recorded approximations and author confirmation; frozen shared
   weights for a new task; feedback arrow. The final edit removed illustrative
   system equations so that the drawing cannot be mistaken for discovered evidence.

These assets are retained in the repository and do not depend on a temporary URL.
